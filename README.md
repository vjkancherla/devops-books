# DevOps Books

A personal library of DevOps and Kubernetes reference books in PDF form, gathered
for study and quick lookup.

## What's inside

- `GitOps-Cookbook-Kubernetes-Automation-in-Practice.pdf` — GitOps patterns and
  automation in Kubernetes (Packt).
- `Ibryam-B-Kubernetes-Patterns-2023.pdf` — Kubernetes design and operational
  patterns by Itay Ibram.
- `Bueno-A-Kubernetes-Secrets-Management-2023.pdf` — Kubernetes secrets management
  best practices.

## How to use

These are reference PDFs rather than runnable examples — open them alongside the
hands-on demos in the other repositories (e.g. `K8s-Voting-App`, `terraform-
examples`, `Devops-Workshops`) for a blend of theory and practice.
