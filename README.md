# DevBooks

A personal library of **DevOps and Kubernetes** reference books (PDF), covering
secrets management, GitOps, and Kubernetes patterns.

## What's inside

- `Bueno-A-Kubernetes-Secrets-Management-2023.pdf` — Kubernetes secrets management.
- `GitOps-Cookbook-Kubernetes-Automation-in-Practice.pdf` — GitOps automation.
- `Ibryam-B-Kubernetes-Patterns-2023.pdf` — Kubernetes design patterns.

## How to use

Open any PDF as a reference. These are reading materials rather than runnable
examples.
